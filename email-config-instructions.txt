# Contact Form Email Settings
# ===========================
#
# This file contains instructions for configuring your email settings
# for the contact form in your NovaEra HMS application.
#
# 1. USING GMAIL:
# --------------
# If you want to use Gmail, you'll need to:
# - Set MAIL_MAILER=smtp
# - Set MAIL_HOST=smtp.gmail.com
# - Set MAIL_PORT=587
# - Set MAIL_USERNAME to your full Gmail email address
# - Set MAIL_PASSWORD to an App Password (not your regular Gmail password)
#   To create an App Password:
#   a. Enable 2-Step Verification on your Google account
#   b. Go to https://myaccount.google.com/apppasswords
#   c. Select "Mail" as the app and "Other" as the device
#   d. Enter "NovaEraHMS" as the name and click "Generate"
#   e. Use the 16-character password that appears
# - Set MAIL_ENCRYPTION=tls
# - Set MAIL_FROM_ADDRESS to the email you want to appear as the sender
#
# 2. USING ANOTHER EMAIL SERVICE:
# -----------------------------
# If you prefer a different email provider like Mailgun, SendGrid, etc.
# check the Laravel documentation for configuration details:
# https://laravel.com/docs/10.x/mail
#
# You should add these variables to your main .env file.
# Do NOT replace your entire .env file with this content.

MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=yourgmail@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@novaera-hms.com
MAIL_FROM_NAME="NovaEra HMS"
